# The Cormorant Tide

## Generation

This story was generated by [danjdewhurst/story-skills](https://github.com/danjdewhurst/story-skills), also using [forjd/better-writing](https://github.com/forjd/better-writing), in Codex with GPT 5.5 xhigh and goal mode.

It was created from a single prompt:

> Write an entire book about a murder mystery in coastal England. You have full creative freedom.

_The Cormorant Tide_ is a complete coastal England murder mystery in Markdown.

When local historian Adrian Rusk is found dead on the tidal causeway to St Osyth's Eye, Detective Inspector Rowan Bell returns to Pelham Hard, the Sussex harbour town she spent years trying to leave behind. What first looks like a cruel accident becomes a murder inquiry tied to a missing notebook, an altered tide board, and the town's most carefully protected story.

The manuscript is restrained, atmospheric, and clue-forward: a contemporary English coastal mystery built around buried truth, loyalty, complicity, grief, and return.
